Gas is priced per unit of work, not per transaction, so a plain transfer costs about 1 riel and heavier operations cost proportionally more. Fees are not burned — they are routed to the public-good fund, which anyone can audit on the Fund page.

Connecting a wallet

CSB is permissioned: an address must hold a KYC attestation and be enabled on the chain's transaction allow list before it can transact at all. A wallet also needs a scoped RPC URL, which returns only your own data — the node's own RPC port is not open to the internet, by design.

Get one from Developer access: connect a wallet, sign a challenge, receive a URL scoped to that address. 

Network name     Cambodia Sovereign Blockchain
New RPC URL      https://<this-host>/rpc/<your-token>
Chain ID         8555
Currency symbol  tRIEL

Check any of this yourself

Everything above is read live from the chain. The raw JSON is at /node-info, and the same values come back from a node directly: 

curl -s -X POST -H 'content-type:application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}' \
  $CSB_RPC_URL
